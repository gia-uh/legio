## Work done (per issue)

### LEG-095 — Phase 1 (report-convergent lifecycle)
- **flow.control**: `STATE_REPORT_SCOPE`, `STATE_REPORT_MESSAGE_TYPE`,
  `ReportedState` (PARKED/READY/TERMINATING), `AgentStateReport` envelope
  (frozen, `extra=forbid`, `schema_version` default SCHEMA_VERSION,
  `message_type` Literal["state_report"], `instance_id`, `action`, `seq` ge=1,
  `state`) — all exported from `legio.flow`.
- **agents.base**: `_deposit_state_report` — unsigned report per honored
  control at neutral priority on the report intake scope; failure is a visible
  `logger.exception` that does **not** change the honor decision. Deposits after
  ENABLE→READY, DISABLE→PARKED, TERMINATE→TERMINATING.
- **runtime**: `STATE_REPORT_TASK` intake fact (`_state_report_fact`): pops one
  report, `AgentStateReport.model_validate` (intake scope, rule 8), correlates
  against the `_pending_controls` ledger keyed `(instance_id, action, seq)`.
  Orphan/mismatch/unknown-instance → WARNING, **consumed, never applied**.
  READY→ENABLED / PARKED→DISABLED via the Registry posteriori; TERMINATING
  informational. Re-kicks the drain while reports remain.
- `enable_instance`/`disable_instance`/`enable_class` converge on the state
  report (`_await_instance_state`), bounded Registry read, **no optimistic
  write** — backlog kept, never minted.
- `destroy_instance` (`DESTROY_INSTANCE` fact, LEG-087): structural terminal;
  on bring-up SUCCESS → `_purge_pending` + kick `STATE_REPORT_TASK`; drain of
  the terminating report is informational.
- `_purge_pending(instance_id)`: removes pending mint(s) for the instance on
  destroy (the drain converges on the structural terminal — a report that never
  arrives is, structurally, the record's terminal; §LEG-087 §5.7/LEG-095 §4.6).

## Decisions taken
- **Report-convergent confirms (LEG-095 §4.5/§5.8)**: enable/disable converge on
  the *state report*, not on an ack. Registry posteriori (report applied on
  intake correlate). No optimistic write on the lifecycle path (rule: mint →
  correlate → posteriori). **No ack by design** (LEG-087 §4.3/§4.8). Destroy
  waits on the structural terminal (bring-up record `success`).
- Orphan/mismatch state reports are **consumed with a visible WARNING** (rule 9
  — never silently dropped), never applied.
