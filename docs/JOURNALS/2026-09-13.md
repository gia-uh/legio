## Decisions taken

- **R-9 before CLI** (maintainer): federation precedes LEG-081. The CLI must
  later support executions in other environments over the federation surface;
  typer was verbally approved for the CLI but stays out of the tree until the
  approved-dependency gate (DEPENDENCIES.md).
- **`legio agent` transport insight** (carried forward to LEG-081): control
  signing keys are per-boot, in-process, never persisted (LEG-082), so a
  separate `legio agent` process *cannot* mint valid control messages — the
  CLI must therefore run as an HTTP client against a running node (or boot the
  node in-process and use the Runtime API directly).
- Capacity derives from the served pattern catalog, not a register (LEG-090
  refresh): one source of truth; legacy `legio.fed` in-memory model stays
  reference-only.
- Invalidation cascades (LEG-070) are naturally the roster's truth: the test
  asserts that a composite depending on an invalidated leaf is itself absent.
