### 3.1 `src/legio/manager/__init__.py` (LEG-083) — modified, additive

The **pre-existing business surface is untouched**: module-level `connect_manager`,
`reset_manager`, `close_manager`, `db`, `submit(client_id, route, payload)`,
`status(task_id, client_id)` (LEG-014/024/025 — used by `api.py`, the flow and
the REST stack). Do NOT change them; they get re-homed under the Runtime in step 3.

Added (new content, coexists):
- `TaskStatus(str, Enum)` = `PENDING | RUNNING | SUCCESS | FAILED | CANCELLING`.
- `TaskRecord(BaseModel)` — `task_id, name, args, kwargs, status, enqueued_at,
  started_at, finished_at, result, error`. **args/kwargs are persisted in the
  record ⇒ must be JSON-serializable** (beaver round-trips JSON). Never put
  `asyncio.Event` or similar into args.
- `Manager` class:
  - ctor `Manager(db, *, node_id, control_ttl=60.0)`; rejects `None` db with
    `TypeError`; validates `node_id` via `legio.naming.validate_node_id`
    (`<name>@<host>`).
  - Scopes: dict `tasks`, queue `pending_tasks`, dict `control`.
  - `register(name, callable)` — in-process only; callable must be async fn or
    async generator (`inspect.iscoroutinefunction` / `isasyncgenfunction`), else
    `TypeError`.
  - `submit_task(name, *args, **kwargs) -> task_id` minted as
    `<node_id>:<uuid>` (validates against `legio.naming.validate_task_id`).
  - `status(task_id) -> TaskRecord | None` (unknown → `None`, no raise).
  - `pause(task_id)` / `resume(task_id)` — non-terminal; `cancel(task_id)` —
    terminal, cooperative.
  - `run() -> int` — ONE polling pass: `pending_tasks.get(block=False)`;
    `IndexError` ⇒ return 0. Pops destructively once — a task executes exactly
    once, a crashed executor is surfaced (record stays visibly `running`), never
    re-run.
  - Dispatch logic in `_dispatch` / `_await_plain` / `_drive_parked`:
    - Plain callables: `await callable(*args, **kwargs)` — success+result |
      failed+error (`logger.exception` on crash).
    - Generator callables: driven step-by-step honoring `control` before each
      yield; `run` advances, `pause` parks in-process (`self._parked`, task
      stays `running`), `cancel` → `CANCELLING` (visible) → `generator.aclose()`
      → `FAILED("cancelled")`.
    - **Result of a generator callable = the LAST value it yielded**
      (`self._last_yields` carries it across parked segments). Python 3.13
      forbids `return <value>` inside `async def` generators.
    - Cancel on a PENDING task → `cancelled` without ever invoking the callable.
    - Pause on a PENDING task → stays `pending`, popped out of the queue;
      `resume` re-enqueues it. `resume`/`cancel` re-enqueue only if
      `PENDING` or parked.
  - Control dict: `{"mode": "run"|"pause"|"cancel"}`, TTL default 60 s;
    absence/expiry ⇒ `run`.
  - Logging: INFO submit/running/parked/success; WARNING cancelled / skip
    re-dispatch / unregistered; ERROR unregistered-name submits;
    `logger.exception` on crashes. Module logger = `logging.getLogger(__name__)`.

### 3.2 `src/legio/registry/__init__.py` (LEG-084) — new module

- `ActivityState(str, Enum)` = `ENABLED | DISABLED`.
- `ClassRecord(BaseModel)` — `name, kind (AgentKind | None), state, queue,
  dependencies`. `kind=None` ⇒ composite (Schema 1: composites carry no kind).
- `InstanceRecord(BaseModel)` — `class_name, instance_id, state`.
  **`instance_id` is the agent's own identity, NEVER a task_id.**
- `Registry` class; ctor `Registry(db)` — rejects `None` db (TypeError).
- Scopes: dict `catalog` (`<name>` → ClassRecord), dict `instances`
  (`<class_name>:<instance_id>` → InstanceRecord), dict `yaml_cache`
  (`<name>` → spec text).
- **Operations (posteriori):**
  - `record_class(name, kind, *, dependencies, queue, state)` — validates kind
    is `AgentKind | None` (non-enum → `ValueError` BEFORE recording);
    duplicate → no-op.
  - `cache_spec(name, yaml)` — upsert.
  - `record_instance(class_name, instance_id, *, state)` — class must exist
    (`KeyError` otherwise — **no orphan instances**); duplicate → no-op.
  - `set_class_state(name, state)` — unknown class → `KeyError` (rule 9).
  - `set_instance_state(class_name, instance_id, state)` — unknown → `KeyError`.
  - `remove_instance(...)` — absent → no-op.
  - `remove_class(name)` — **armageddon** (§4.5): removes the class and ALL its
    instances; the YAML stays cached. Absent → no-op.
- **Queries (granular, read-only):**
  - `list_classes()`, `class_state(name)` (→ effective state; `None` if absent),
    `class_dependencies(name)` (unknown → `KeyError`),
    `class_dependents(name, *, transitive=False)` (unknown → `[]`; transitive =
    the §7 upward cascade, computed by BFS over the catalog, never stored),
    `dependencies_satisfied(name)` (each dependency effective-enabled,
    §4.2/§4.3), `list_instances(class_name)`, `get_instance(class_name,
    instance_id)`, `get_cached_spec(name)`.
- **Effective state §4.4:** stored `enabled` AND ≥1 recorded instance ⇒
  `enabled`, else `disabled`. **Dependencies are NEVER part of the
  derivation** (a conscious enable with missing deps stays enabled).
- Logging: INFO on record/set/remove/cache; WARNING on no-ops; ERROR on rule-9
  denials (`registry unknown class=…`, `registry record_instance deny …`).

### 3.3 Behavior gotchas (learned this session — don't rediscover)

- `beaver` dict `items()`/`values()` already deserialize; `fetch(key, default)`
  returns the dict/str as-is. There is no invented substrate layer; use
  `db.dict(scope)` / `db.queue(name)` / `db.lock(name)` directly.
- `dict.items()` triggers `PERF102` in ruff when only values are used — use
  `.values()`. `pytest.raises(Exception)` triggers `B017` — use the concrete
  exception (`KeyError`/`TypeError`/`ValueError`).
- Walrus with `await` in an expression (`x := (await …)`) → SyntaxError; assign
  first.
- `buffer` no longer used as a JSON storage stream for manager records; the
  generic Manager persists `TaskRecord.model_dump(mode="json")` directly.
