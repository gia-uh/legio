### LEG-104 / #53 — shipped examples run as documented (implemented, green)
- **`src/legio/config.py`**: new `resolve_config_paths(loaded)` anchors relative
  `database.db_path`, `patterns.*` and `tools.config` to `config_path.parent`.
  `load()` stays a **pure parse** (its verbatim-path tests stand); the helper
  returns the *same* config object when every path is absolute (identity is
  observable via `BootedNode.config is loaded`).
- **`src/legio/tools.py`**: `AvailableToolsRegistry(base_dir=...)`. `load_tool`
  tries a normal dotted import first, then falls back to a **node-local** file
  `<base_dir>/<module>.py` loaded by file location under a unique synthetic
  module name (no `sys.path` mutation, no cross-node collision); loaded
  callables are cached per registry.
- **`src/legio/materializer.py`**: `boot_node` resolves the config, creates a
  missing `db_path.parent`, and passes the tools-config directory as
  `base_dir`.
- **`src/legio/cli.py`**: the catalog collector and the `validate` dir resolver
  use the resolved config, so `legio validate --config examples/...` and the
  boot path agree.
- **Examples**: removed the shared `examples/tools.py` and `examples/__init__.py`;
  each tool-bearing node now ships its own `tools.py` beside `legio.yaml`
  (`tools.transform`, `tools.assess`, `tools.pdf_extract_text`).
  `document_processing/tools.py` imports `pypdf` **lazily** and ships
  `requirements.txt` (example-only dependency).
- **Tests**: new `tests/test_leg104_shipped_examples.py` (3) — (1) the README

  `{"transform": {"transformed": "HELLOHELLO"}}`; (2) every shipped config
  resolves and every declared tool loads; (3) every shipped config validates.
  `test_leg100` now loads tools through the real node-local registry;
  `test_leg063`/`test_leg064` use `tests.tools.transform`.

## Decisions taken

- **Split #52 per finding** (maintainer); execution order #53 → #54 → #55 →
  #56 (cut `v0.1.1`) → #57 → #58.
- **Release**: cut `v0.1.1` from the corrected, validated tip; do **not**
  rewrite the published `v0.1.0` (maintainer).
- **`pypdf` is example-only** (maintainer): node-local tools + the example's
  own `requirements.txt`. Removing it from `legio`'s `pyproject.toml` and adding
  the `DEPENDENCIES.md` row are **LEG-107**, not this slice.
- **LEG-108 trust model** (maintainer): the node receiving a user request
  authenticates the user; a peer presenting the federation token is trusted.
  What is required is that the configured **peer allowlist is enforced in the
  implementation** (the tests validate it) — no per-`task_id`-author isolation.
- **Config-relative resolution at the node boundaries**, not in `load()`
  (keeps `load()` pure and its tests meaningful); `resolve_config_paths`
  preserves object identity when nothing is relative.
- **Node-local tool loading is a file-location import**, not a `sys.path`
  mutation, so two nodes' `tools.py` never collide in one process.
