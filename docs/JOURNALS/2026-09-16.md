- **Independently verified major findings:**
  - Tool execution does not match the declared tool policy: `src/legio/agents/tool_agent.py:73` invokes the loaded tool synchronously, while timeout/retry policy is declared in `src/legio/config.py:292-296` and stored in `src/legio/tools.py:37-50` but never consumed by tool execution.
  - Composite pending-gather uses an unbounded `asyncio.sleep(0.01)` poll in `src/legio/agents/composite_agent.py:175-182`, without a monotonic deadline or backoff.
  - Composite fan-in is documented as guarded by a lock in `docs/ARCHITECTURE.md:217`, but targeted source inspection found no beaver lock acquisition call sites; `src/legio/agents/composite_agent.py:238-359` performs fetch, mutate, set, and delete without exclusion.
  - Legacy federation state remains global and process-resident in `src/legio/fed.py:80-101`; production federation only needs the interface type in `src/legio/federation.py:43`, while `src/legio/materializer.py` uses the newer `federation` plane and `tests/test_leg015_federation.py` still exercises `fed`.
- **Independently verified boundary correction:**
  - `src/legio/cli.py:724-730` boots the node before checking for `LEGIO_FEDERATION_TOKEN`; the refusal is loud, but the order is boot-then-refuse, not refuse-before-boot.
- **Accepted as audit evidence after source checks:**
  - Positive load-bearing invariants still hold: federation has no engine imports; patterns remain compiler-pure YAML data; agents do not import Runtime/Manager; transport does not mint lifecycle; substrate naming remains native beaver; no consumer-domain identifiers were found in `src`.
  - Minor coupling/hygiene debt includes the agent-to-registry enum import, cross-module private Runtime field write, duplicate ledger initialization, unclosed proxy-owned HTTP client lifecycle, poll-minted drain-task growth, silent pause-TTL reversion, unused auth middleware versus inline API enforcement, parked in-memory held work, queue deletion during iteration, non-monotonic drain accounting, duplicate YAML ingestion, unlogged token-store mutations, unstable error-code fallback, and peer-filter approximation.
  - Notes include non-English strings, dual `fed`/`federation` naming, implicit environment/host/clock seams, proxy lifecycle hazard, loader TODO, and embedded no-catalog fallback.
